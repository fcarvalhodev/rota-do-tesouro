# Rota do Tesouro

A dívida do Brasil explicada de um jeito simples: dever em reais ou em dólar (Brasil, Argentina e Estados Unidos), o tamanho da dívida ao longo dos governos, quanto custam os juros, quem paga, quem recebe e o que custa mais caro.

Faz parte das [Rotas](https://fcarvalhodev.github.io/rotas/). Cada número traz o link da fonte.
